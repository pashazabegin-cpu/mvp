# MVP — первый экран (hero)

Прелоадер (Lottie) → интро → 5 слайдов по 5 секунд с прогрессом в навигации → переход наклонными полосами (16.76°).
Один модуль на чистом TypeScript + GSAP, без фреймворков. Работает поверх серверной разметки.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # проверка типов + сборка в dist/
```

Демо-сборка для показа: `npm run build` → папка `dist/` (и `MVP-hero-v1.zip`). Открывается двойным кликом по `index.html`, без сервера — JS, CSS, шрифты и прелоадер встроены в страницу, видео и картинки лежат рядом в `hero/`.

Демо-параметры: `?slide=3` — сразу на слайд, `?pause` — без автопрокрутки, `?nopreload` — без прелоадера, `?static` — мгновенно доигрывать анимации (для скриншотов).

## Что где

| Файл | Что делает |
|---|---|
| `index.html` | разметка экрана — её нужно перенести в PHP-шаблон как есть |
| `src/hero/index.ts` | `initHero()`: масштаб, автопрокрутка, прогресс, переход, интро, свайп, клавиши |
| `src/hero/strips.ts` | переход «полосами» — одна маска `clip-path: polygon()`, любой угол |
| `src/hero/reveal.ts` | появление/уход текстов слайда (`data-anim="tag | parts | lines | btn"`) |
| `src/hero/effects.ts` | магнит к курсору |
| `src/hero/gl.ts` | минимальный WebGL-слой (один полноэкранный шейдер) + режимы наложения как в Figma |
| `src/hero/rating.ts` | «Рейтинг»: «лесенки», свечения и свет за курсором одним шейдером |
| `src/hero/duo.ts` | «Премия и форум»: фон из Figma, растущий луч, Linear burn и Screen логотипов одним шейдером |
| `src/hero/progressive-blur.ts` | progressive blur из макета (`data-pblur`) |
| `src/hero/glow.ts` | светящиеся эллипсы (`data-glow`) — градиентом вместо тяжёлого SVG-блюра |
| `src/hero/preloader.ts` | Lottie-прелоадер, ждёт шрифты и видео первого слайда |
| `src/hero/hero.css` | стили; координаты — пиксели макета 1600×900 |
| `public/hero/` | ассеты: видео, фото, SVG, шрифты, `preloader.json` |

## Как подключить в существующий сайт (Vite + `app.ts`)

1. `npm i gsap lottie-web`
2. Скопировать `src/hero/` в проект, ассеты `public/hero/` — в папку статики (например `/assets/2026/hero/`) и поправить пути в разметке и в `@font-face` в `hero.css`. Шрифты Space Grotesk уже лежат на сайте в `/assets/2026/fonts/` — можно сослаться на них.
3. В `app.ts`:
   ```ts
   import './hero/hero.css';
   import { initHero } from './hero';

   const el = document.querySelector<HTMLElement>('[data-hero]');
   if (el) initHero(el, { onReady() { /* прелоадер ушёл — можно запускать остальную анимацию страницы */ } });
   ```
4. Разметку `<section class="hero" data-hero>…</section>` из `index.html` перенести в шаблон главной.

API: `initHero(el, options)` возвращает `{ next, prev, goTo(i), pause, play, destroy }`.
Опции: `autoplay` (мс, по умолчанию 5000), `angle` (16.76), `stripCount` (10), `revealDuration` (0.5), `stripStagger` (0.04), `zoomFrom` (1.2), `zoomDuration` (0.9), `onReady`, `onChange(i)`.

## Заметки

- **Почему «Рейтинг» и «Премия и форум» на WebGL.** Их фон собран из режимов наложения (overlay, hard-light, color-dodge, plus-lighter, Linear burn). CSS `mix-blend-mode` внутри анимированной маски перехода Chrome рисует с артефактами (белые и пустые прямоугольники) и тормозит при первом показе. Шейдер считает те же формулы сам, для браузера это обычная картинка, как видео. Шейдеры компилируются и рисуют первый кадр ещё под прелоадером.
- Фон «Премии и форума» — рендер из Figma 2x (`bg-base.jpg` без луча, `bg-ray.jpg` с лучом). Луч раскрывается кругом из точки внизу, в конце картинка 1:1 с макетом. Синий логотип — честный Linear burn, розовый — Screen; оба двигаются за курсором (GSAP анимирует невидимые `.duo-logo`, шейдер читает их положение).
- Без WebGL остаётся HTML-версия этих слайдов (слои в разметке под `<canvas data-gl>`).
- Текстуры WebGL задаются в `data-tex-*` у canvas. В демо-сборке они встраиваются в страницу (с file:// браузер не даёт грузить картинки в WebGL), на сайте — обычные ссылки.
- Видео перекодированы в 1080p H.264 без звука, с индексом в начале файла (играют до полной загрузки): «Премия» 7.4 МБ → 0.77 МБ, «Форум» 14 МБ → 2.6 МБ (2 Мбит/с), «Квизмас» 0.9 МБ → 0.6 МБ. У каждого есть постер — первый кадр.
- Видео первого слайда грузится сразу (его ждёт прелоадер), видео «Форума» и «Квизмаса» — после прелоадера (`data-deferred`), чтобы не отнимать канал у первого экрана.
- `prefers-reduced-motion`: переход становится простым растворением, магнит и параллакс отключаются.
- На тач-устройствах — свайп; магнит к курсору не включается.
- Мобильная раскладка в `hero.css` — временная заглушка: мобильные макеты будут отдельно.
